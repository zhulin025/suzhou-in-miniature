# 多城市版本验收记录

本次新增 16 座城市，原苏州与 v2 保留。新增场景共 64 个地标视点、16 家开放店铺。所有数字来自本地程序和浏览器验收；地形、距离及建筑比例为艺术化缩景。

## 几何与步行

`node scripts/validate-city-geometry.mjs` 成功退出。

- 16 / 16 城顶点、法线有效，所有地标起点、店铺门口和店内落点可行走。
- 道路中心线按 1 单位采样，阻挡数为 0。
- 15 城从默认起点完全连通；温州江心屿保留与大陆隔水的关系，三个岛上地标通过漫游顶部起点选择框抵达。三个落点分别合法，且岛内步道互通。
- 无意外隔绝的目标。完整记录：[city-geometry.json](../artifacts/city-geometry.json)。

## 浏览器与输入

使用 Ego Browser 的真实 WebGL2 页面；桌面视口 1440 × 1000，DPR 1，种子 310528。

- 16 / 16 页面直接加载成功，运行时错误列表为空；逐城保存日景、地标近景、夜景与步行画面。
- 64 个地标镜头坐标有效；64 个漫游目的地可通过选择框抵达。
- 每城真实点击昼夜按钮、开启漫游、按 W 行走并以 Esc 退出；移动距离约 4.1–4.3 场景单位，移动后位置合法。
- 桌面拖动旋转实测相机位移 150.29；滚轮将相机距离从 403.95 缩至 306.22；右键平移目标 8.11 单位。关于弹窗、Esc 关闭与 PNG 捕获接口通过。
- 手机模拟视口 390 × 844，DPR 2：列表有 17 张卡片且无横向溢出，搜索“山西大同”只返回大同，选择后进入对应页面。
- 两个同时存在的触点可分别操作摇杆与视角；取消触摸后摇杆归中，后续 20 帧的水平位置保持不变。已检查手机起点选择器与长城市名称布局。这是触摸模拟结果，未声称实机验收。
- 已实际查看线框与水面法线诊断，渲染不使用屏幕后处理。

最终记录：[validation.json](../artifacts/cities/validation.json)。一轮重启浏览器脚本时曾产生两个自动化流程争用页面的导航错误；受影响的六城随后串行复验全部通过，保留原始尝试及复验记录供追溯。

本次截图中，场景约 12.4–41.7 万三角形、36–57 次绘制调用。稳定夜景采样的 RAF 间隔为 31.77–33.89 ms；该数字受测试浏览器调度影响，不是 GPU 计时或所有设备的性能保证。

## 构建与入口

`npm run build` 成功，包含原版、16 个城市页面、城市列表与 v2。Three.js 共享包仍有 Vite 的 500 kB 体积提示，不影响构建。区域模型按需加载，只生成当前城市；城市列表没有 WebGL canvas。

本地生产预览的 19 个页面入口均返回 HTTP 200。日常预览入口为 [城市小境](http://127.0.0.1:5173/cities.html)。上述验收均在本地完成；发布版本以 GitHub `main` 分支及 Vercel 最近一次成功的生产部署为准。
