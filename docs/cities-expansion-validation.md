# 八城扩建验收（2026-10-03）

## 结果

- 新增八座城市均可独立加载，分别有 4 个地标、2 间原创开放小店。
- 桌面逐城实测：缩放按钮、画布拖动旋转、昼夜渐变、四处地标相机、漫游起点切换、WASD 移动、Esc 退出，无运行时错误。
- 390 × 844 手机尺寸逐城实测：摇杆斜向移动、松手停止、右侧拖动环顾、touchcancel、退出漫游、页面无横向溢出。此为浏览器触控模拟，不是真机验收。
- 逐城从第一家小店的门口使用 W 键走进室内；全部通过。第二家小店同样通过实际碰撞函数的门口与室内连通性检查。
- 24 个共用引擎城市的几何检查全部通过：有限坐标与法线、地标及店铺位置、道路采样无阻塞；原有 16 城一起回归。苏州为独立原版引擎。
- 鼓浪屿及原有江心屿保持真实海岛属性，使用地标漫游入口上岛。验证明确检查岛内连通，不声称可以从大陆步行上岛。
- 25 城列表使用实际场景 WebP，新增 8 张约 157 KB；卡片直接进入页面，支持搜索及动态地区筛选。

## 复现

- `node scripts/validate-city-geometry.mjs`
- `npm run build`
- Ego Browser：在当前 QA TaskSpace 中运行 `scripts/validate-expansion.mjs`、`scripts/validate-expansion-mobile.mjs`；运行前将脚本 TaskSpace ID 与 Page 标签改为该次测试创建的空间。
- 浏览器汇总：`artifacts/city-expansion-validation.json`。
- 来源、建模范围及实际模型清单：`docs/cities-expansion.md`。

生产构建包含根页面、城市列表、24 个独立城市页面及 v2。Three.js 共享包的既有 500 KB 体积提示仍存在；构建无错误。
