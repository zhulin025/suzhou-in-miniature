# 八城扩建：地点依据与实际模型

这批场景沿用城市小境的 Three.js 实体几何与柔和微缩风格。比例、距离、街巷和地标组合均为艺术化压缩，不是测绘数据；不把周边景区误作真实市中心布局。2026-10-03 实现。

## 已实现的原创小店

每城两间店。均有开放门口、侧墙、后墙、可绕行柜台、三层货架、立体商品与招牌，可从街道走进室内。商店名称为本项目原创，无实际营业或交易功能。

- 重庆：山城小面、江畔茶馆。
- 西安：长安面坊、城南书肆。
- 桂林：漓岸米粉、山水书屋。
- 哈尔滨：雪街面包坊、松江书屋（山墙坡屋顶）。
- 厦门：海风沙茶面、岛上书房（山墙坡屋顶）。
- 泉州：古巷面线糊、刺桐茶铺。
- 拉萨：日光甜茶馆、高原书屋（平顶檐口）。
- 敦煌：沙洲面馆、丝路书铺（平顶土色街屋）。

## 共用功能与新增能力

| 原有能力 | 本批实现 | 入口与验收 |
| --- | --- | --- |
| 旋转、缩放、地标定位 | 复用 OrbitControls，每城四个独立地标模型与取景点 | 拖动、滚轮、右侧工具及底部地标按钮 |
| 昼夜 | 全部城市窗口/街灯渐亮；哈尔滨冰塔另有蓝色夜间发光 | 白昼/入夜按钮、N 键 |
| 步行与触控 | 复用 WASD、碰撞、手机摇杆与拖动环顾；沙丘采用与地形相同的高度函数 | 开启漫游、漫游起点选择器、Esc 退出 |
| 开放小店与商品 | 每城独立店名、位置、店内货架和商品；新增平顶/山墙屋顶选项 | 从门口进入；逐店检查门口与内部连通性 |
| 树木与街具 | 棕榈、松树、落叶树按城市选择；树干、分枝、冠层、树穴与路灯、座椅 | 地标近景与街道步行观察 |
| 水面与船只 | 各有水城市共用动态水面与船；无水的拉萨不添加江南河道 | 白昼与夜间观察 |
| 城市专属动态 | 重庆往返索道；哈尔滨飘雪与冰雕夜光 | 独立动画回调，不改动其他城市的动画 |
| 城市列表 | 25 城，筛选类别根据目录生成；每张卡片直接链接城市 | 搜索、区域筛选、单次点击、场景画布实景 WebP |

无名远景街屋、山体、船只、行人、路灯和店铺都是艺术化环境模型；不将它们当作额外真实地标。未增加车辆驾驶、商品交易或真实宫殿/石窟室内。

## 验证

- `node scripts/validate-city-geometry.mjs`：真实碰撞函数的逐点道路检查、地标/店铺门口/室内安全位置、网格连通性及有限几何坐标。鼓浪屿与原有江心屿明确按独立海岛处理，并分别检查岛内连通。
- `npm run build`：全部 25 页及保留的 v2 构建。
- 浏览器逐城验证渲染、昼夜、地标近景、WASD、退出、手机尺寸界面与触控；实际结果记录在扩建验证报告中。
- 卡片使用当前 Three.js 画布截图，不使用外部图片代替场景。
