# 南京、北京、大同、青岛、大连：模型清单与参考

这些场景是把同一城市的多个地点压缩进一块微缩地形的艺术化创作，不是地图、测绘成果或文物复原。坐标只标示城市，不表示模型中各建筑的实测位置。所有建筑和雕塑均为真正的 Three.js 三维几何；无用照片冒充的立面、无网络下载模型。文物建筑仅表现外观；店铺是原创、可进入的情境空间，不声称还原真实商家。

## 南京

- **中华门瓮城**：4 道真实开口券门、3 个连通瓮城、侧墙、垛口、砖缝。通道可步行穿过。核查重点是四门贯通三瓮城，门洞和各道墙体的高度作微缩简化。[南京市文旅局：天下第一瓮城](https://wlj.nanjing.gov.cn/ztzl/mcq/gzqk/202302/t20230228_3838766.html)
- **夫子庙与秦淮河岸**：黄色屋顶大殿、柱列、牌坊、院墙、河对岸照壁、2 座跨河步桥、2 艘动态画舫。庙、照壁、河道的相对关系有来源，沿岸街屋为原创组合。[南京市政府：秦淮画舫及泮池码头](https://www.nanjing.gov.cn/zgnjsjb/jrtt/202407/t20240701_4702756.html)
- **中山陵祭堂**：蓝瓦、浅色祭堂、3 个正面门洞、层叠台阶、栏柱、下方牌坊。核查蓝色琉璃瓦、白色石材、中轴长阶；模型台阶数量和地势经过压缩。[中山陵园管理局：中山陵景区](https://zschina.nanjing.gov.cn/fjms/jqjd/zsljq/)
- **情境**：41 栋旧街住宅，原创开放书店「秦淮书舍」，两岸柳树与城北林荫、照明小品。街屋数是运行代码的实际调用统计，不含地标。

## 北京

- **祈年殿**：3 层白色圆台、24 根外圈柱、3 道蓝色圆形攒尖檐、实体瓦缝、金色宝顶。重点核查圆形、三重蓝檐和白色台基；比例和柱数是模型表达，不宣称等同原物。[北京市文旅宣传：天坛建筑](https://english.visitbeijing.com.cn/article/47ONy6AX0b3)
- **故宫太和殿意象**：3 层白石平台、金色重檐庑殿顶、红柱、窗格、院墙、角部屋顶与 3 个真正可穿行的院门。核查太和殿重檐屋顶与三层白石基座；仅选择主殿和院落意象，不是完整紫禁城。[故宫博物院：太和殿](https://www.dpm.org.cn/explore/building/236465.html)
- **北海白塔**：白色覆钵塔身、12 个简化相轮、红底装饰、金色塔刹、水中岛、步桥。采用北海而非妙应寺白塔的参考；相轮数量、岛屿轮廓和塔身曲线均为微缩设计。[北京市文旅宣传：北海白塔](https://english.visitbeijing.com.cn/article/47OOEDJ05m0)；[北京市政府：北海公园](https://english.beijing.gov.cn/specials/parktours/guidevisitors/beihaipark/index.html)
- **鼓楼街景**：高台真实券洞、红色楼身、灰瓦重檐。是鼓楼类型的风貌重构，未声称精确复刻历史平面。
- **情境**：12 组 3 翼胡同院落（36 栋）加 4 栋背景住宅，原创开放茶馆「胡同小茶馆」，松林、轴线林荫和湖岸步道。

## 山西大同

- **云冈石窟意象**：有厚度的岩壁、主龛空间、2 个小龛、立体坐佛、盘坐双腿、双臂手部、面部、衣褶、岩层。不称为第 20 窟的准确复制；资料支持云冈大像窟与坐佛文化特征，洞窟组合、面部和衣褶是原创简化。[大同市政府：行走云冈](https://www.dt.gov.cn/dtszf/bumdtq/202406/dd5b90433a5e4757a7b9442888deaf2e.shtml)；[国家民委：云冈石窟佛教艺术](https://www.neac.gov.cn/seac/c103391/202306/1164735.shtml)
- **华严寺大殿意象**：横向宽屋顶、红柱、多层斗栱、庭院边墙。来源支持辽金寺庙与宏阔佛殿；模型没有宣称实测开间、东向方位或文物室内。[大同市政府：境外来同人员城市服务指南，华严寺条目](https://www.dt.gov.cn/dtszf/bumdtc/202502/876623c1c40a4b618d02f28318861845/files/aaed7dbcd3524e3bb4b9c716c0235308.pdf)
- **九龙壁**：9 条分别建模的曲线龙身、龙首、眼睛、角、爪，蓝绿金色釉砖与瓦顶。9 条龙是明确定义的几何，不是纹理；釉色位置及龙纹不是原物临摹。[大同市英文门户：九龙壁](https://www.dt.gov.cn/english/placestovisit/202501/916d3d6f6ec14655978f5a3212ee06b6.shtml)
- **大同城门**：高砖台、中央真实券洞、重檐城楼、左右城墙和垛口。为古城墙风貌组合，不冒用某座城门的精确形制。
- **情境**：40 栋灰砖旧街住宅，原创开放小店「古城面香」，宽街与松树林。

## 青岛

- **栈桥、回澜阁**：长形栈桥、栏杆、末端扩大的台地；阁体为真正八角平面、2 层飞檐、金色屋瓦及红柱。参考核查双层八角阁与桥端平台；模型平台轮廓和桥长为压缩表达。[青岛市政府：栈桥](https://www.qingdao.gov.cn/yfqd/qdwl/cjfw/wyqhb/202009/t20200902_518755.shtml)
- **五月的风**：有厚度、闭合侧面的红色连续螺旋体；不是平面图，也不是堆叠的圆环。参考支持螺旋向上的钢体结构，卷曲曲线为艺术化重构。[青岛市政府：扬帆青岛，五四广场条目](https://www.qingdao.gov.cn/yfqd/)
- **圣弥厄尔教堂**：黄褐墙体、2 座高塔、红色尖顶和十字架、玫瑰窗辐条、十字形体量。未还原宗教室内。来源确认双尖塔与十字形平面。[青岛市政府：天主教堂](https://www.qingdao.gov.cn/yfqd/qdwl/cjfw/wyqtsjd/202009/t20200910_521996.shtml)
- **小青岛灯塔**：白色渐收塔身、环形挑台、灯室结构和顶部小锥屋顶，位于离岸岛上。只提供岸边观看点，未添加虚构步行堤连接岛与陆地。[青岛市政府：扬帆青岛，小青岛公园条目](https://www.qingdao.gov.cn/yfqd/)
- **情境**：39 栋红瓦洋房、3 栋现代台阶式楼房，原创开放书店「海风小书屋」。邻里用坡顶、烟囱、窗框、小角塔表现青岛红瓦街区；不把任意住宅标注成真实历史单体。

## 大连

- **星海湾跨海大桥**：2 层桥面、交叉钢桁架、2 座门形主塔、双侧抛物悬索、垂直吊杆及桥面灯带。桥为岸边观赏景物，不提供虚构人行上桥功能。几何保留双层悬索桥结构类型，桥长、曲线和跨距压缩。[设计方大连理工大学：桥梁设计的里程碑](https://inv.dlut.edu.cn/info/1002/1136.htm)
- **星海广场意象**：开阔圆形铺地、放射状石线、两片曲面形成的翻页雕塑。此处是艺术化场景，不主张照录铺地图案或纪念雕塑尺寸。
- **中山广场街廓**：圆形广场、放射状铺地线、5 座带柱廊/穹顶/线脚的近代街区立面。圆形布局有大连公共图书馆资料支持；各单体是原创风貌建筑，没有冠以真实银行或旅馆名称。[大连图书馆地方文献：中山广场](https://www.dl-library.net.cn/wenxian/dlnet/content.php?id=41651)
- **俄罗斯风情街**：彩墙、坡屋顶、尖角塔、窗格、沿街开放咖啡店。资料支持街区作为既有历史建筑和商业街的情境；几何单体与室内为原创设计。[大连西岗区政府：风情街提案答复](https://dlxg.gov.cn/xxgk/zdlyxxgk/jycabl/gzxca/2026/189196.htm)
- **情境**：24 栋港城洋房、6 栋现代背景楼、5 座近代广场立面、1 间「海港小咖啡」，另有匿名航标灯塔与 2 艘帆船。灯塔不冒用具体真实航标名。

## 验证范围

用真实共享 `createCityContext → build → finish` 在 Node 中建立 5 个场景，检查全部几何坐标有限。初次构建三角形数量约为南京 32.6 万、北京 30.8 万、大同 28.0 万、青岛 12.4 万、大连 13.0 万；包含环境、树木和水体，远低于每城 60 万目标。浏览器招牌会增加少量面数。

每城开放店铺的门外点与内部点均通过 `isWalkable`。道路中心线逐米抽样无阻挡。南京、北京、大同的所有地标步行点和店铺内部从默认出生点网格寻路可达。青岛、大连显式提供岸上出生点，以免自动选择海岛或水域边界；从各自指定的岸上出生点再次执行网格寻路，所有地标观看点与店铺内部均可达。最终浏览器验证由主任务执行。
